# Linux TUI

This is the first native Linux milestone for the Albion Online Statistics
Analysis Tool. It is intentionally a terminal UI rather than a WPF port.

## Setup

Debian 13 needs .NET 10 and libpcap:

```bash
wget https://packages.microsoft.com/config/debian/13/packages-microsoft-prod.deb -O /tmp/packages-microsoft-prod.deb
sudo dpkg -i /tmp/packages-microsoft-prod.deb
rm /tmp/packages-microsoft-prod.deb
sudo apt-get update
sudo apt-get install -y dotnet-sdk-10.0 libpcap0.8 libpcap-dev
```

If `sudo` is not available in the current shell, install the SDK locally:

```bash
curl -L https://dot.net/v1/dotnet-install.sh -o /tmp/dotnet-install.sh
bash /tmp/dotnet-install.sh --channel 10.0 --install-dir /tmp/dotnet --no-path
```

## Build

```bash
dotnet restore src/StatisticsAnalysisTool.Linux.sln
dotnet build src/StatisticsAnalysisTool.Linux.sln -c Debug
```

With the local SDK:

```bash
/tmp/dotnet/dotnet restore src/StatisticsAnalysisTool.Linux.sln
/tmp/dotnet/dotnet build src/StatisticsAnalysisTool.Linux.sln -c Debug
```

In constrained shells where compiler-server or MSBuild IPC is blocked, use:

```bash
/tmp/dotnet/dotnet build src/StatisticsAnalysisTool.Linux.sln -c Debug -m:1 /p:UseSharedCompilation=false
```

## Run

```bash
./run-linux-tui.sh
```

The web UI can be run with:

```bash
./run-linux-web.sh
```

It listens on:

```text
http://127.0.0.1:5050
```

The v1 TUI supports:

- startup/status view
- libpcap device enumeration
- live libpcap capture start/stop
- Photon UDP payload delivery into the shared parser
- parsed Photon event/request/response counters
- DPS meter from health update events
- loot logger from loot events
- silver, fame, respec, faction, standing, might, and favor per-hour counters
- item names from `IndexedItems.json` generated by the old Albion data extractor
- entity names learned from join, character, party, loot-body, and mob packets
- settings save/load
- log/status pane
- dark terminal color scheme with highlighted section focus

Keyboard shortcuts:

- `Up` / `Down`: change the selected section while the section list is focused
- `F2`: save settings
- `F3`: focus the interface list from the Devices section
- `Space` / `Enter`: toggle the focused interface in the Devices list
- `Tab`: move into editable settings fields from the Settings section
- `Esc`: return focus from a settings field or interface list to section navigation
- `Ctrl+Q`: quit
- `F5`: refresh status and capture devices
- `F6`: start or stop live capture
- `F7`: reset the DPS meter
- `F8`: reset loot and per-hour counters
- `F9`: export item loot as an HTML report with Albion render icons

`Ctrl+S` is intentionally not used because many Linux terminals treat it as
XOFF flow control and pause terminal output until `Ctrl+Q`.

Settings are saved to:

```text
~/.local/share/StatisticsAnalysisTool/Instances/Default/LinuxSettings.json
```

Settings currently editable from the Settings section:

- `serverLocation`: defaults to `Europe`
- `packetFilter`: optional libpcap/BPF packet filter
- `logLevel`: stored for later logging controls
- `selectedDeviceIdentifiers`: comma-separated libpcap device ids from the
  Devices pane
- `mainGameFolderPath`: Albion install folder; used to generate
  `IndexedItems.json`
- `gameDataDirectory`: optional folder containing an existing `IndexedItems.json`
- `gameDataLanguage`: item name language, defaults to `en-US`
- `localPlayerName`: character name used for local-only loot filtering when
  capture starts after you are already logged in

The default generated item file location is:

```text
~/.local/share/StatisticsAnalysisTool/Instances/Default/GameFiles/IndexedItems.json
```

If `mainGameFolderPath` is set, restart the TUI after saving settings so the
item index can be generated and loaded.

## Current Limits

This milestone starts Linux packet capture, feeds Photon UDP payloads into the
shared parser, and exposes Linux-native DPS, loot, and rate views.

Some desktop app enrichment is still pending:

- Entity names appear after the relevant packets have been observed in the
  current capture session; unknown rows still fall back to entity ids.
- DPS rows are limited to the local character and known party members.
- Loot item names require `IndexedItems.json`; unknown rows still fall back to
  item indexes.
- Loot logger rows are item pickups only. Silver bags and picked-up silver are
  tracked in Rates, filtered to the local character when local identity is known.
- Market value and silver-per-loot totals need the old item price data pipeline.
